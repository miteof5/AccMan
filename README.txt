# 原神舰长账号管家

半自动登录辅助工具：把账号密码加密存在本机，点一下自动送进原神登录框，
登录按钮你自己点（更稳、风控风险更低）。

## 使用方法

1. 双击 `启动工具.bat` 打开工具窗口。
2. 点「添加账号」，填备注（如舰长昵称）、账号（邮箱/手机号）、密码。
3. 打开原神客户端，停在登录界面。
4. 回到工具，点该账号行的「填入登录框」。
5. 工具自动把账号、密码依次填入原神登录框 —— 然后你在原神里点登录。
6. 滑块验证码需要你手动划一下。

## 文件说明

| 文件 | 作用 |
|---|---|
| `启动工具.bat` | 双击启动 |
| `main.py` | 图形界面 |
| `accounts.py` | 账号存储 |
| `credentials.py` | 密码加密（Windows 系统级，绑定本机当前用户） |
| `login_fill.py` | 自动填入登录框（等待登录界面截图后启用） |
| `accounts.enc` | 加密后的账号数据文件（不出现明文） |
| `vendor/` | 工具自带依赖，不要删 |

## 安全说明

- 账号密码用 Windows 系统加密（DPAPI）保存，绑定本机当前 Windows 账户；
  密文文件被别人拷走也解不开。
- 此工具只用于登录你有权限托管的账号（舰长自愿交给你的）。
- 自动化操作有被平台风控的可能，请自行权衡风险。
