# AccMan · 原神账号管理器

帮你在多个米哈游通行证账号之间快速切换：把账号密码自动填入原神客户端登录框，你只需手动点「进入游戏」。

## 功能

- 账号列表管理（添加 / 删除 / 编辑 / 搜索）
- 点击卡片 → 自动把账号密码填入原神登录框（OpenCV 模板匹配定位 + 剪贴板粘贴）
- 密码本地 DPAPI 加密存储（绑定当前 Windows 账户，别人拷走文件也解不开）
- 填完自动清空剪贴板，避免明文密码残留

## 使用（免安装）

1. 下载 `dist/accman.exe`
2. 双击运行（首次会在同目录生成 `accounts.enc`）
3. 点「＋ 添加账号」录入舰长账号
4. 打开原神到登录界面 → 回到工具点对应卡片 → 手动点「进入游戏」

## 从源码运行

```bash
pip install -r requirements.txt
python run.py
```

## 说明

- **半自动**：只负责填入账号密码，登录按钮和滑块验证由你手动完成，行为与真人一致，降低风控风险。
- **坐标适配**：模板匹配基于 1920×1080 分辨率下的 miHoYo 登录界面。分辨率或界面缩放不同时，按 `config.json` 里的 `offsets` 微调。
- 账号数据文件 `accounts.enc` 在 exe 同目录，备份 / 换机直接拷这个文件。
